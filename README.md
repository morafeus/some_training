незаконченным, меняться или ломаться.

## Что здесь лежит

Пока пусто — проекты будут появляться по мере изучения.

## Как пользоваться

1. Клонируй репозиторий:


2. Зайди в папку проекта и следуй инструкциям в его README (появятся позже).
